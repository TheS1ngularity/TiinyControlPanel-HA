# Tiiny Control Panel for Home Assistant

A Home Assistant add-on repository with one add-on: the community
[Tiiny Control Panel](https://github.com/0xStian/tiiny-control-panel), shown in the Home Assistant sidebar.

This is an independent packaging. It isn't affiliated with Tiiny or with the panel's author.

## Install

1. Settings → Add-ons → Add-on Store → ⋮ → Repositories, and add this repository's URL.
2. Install **Tiiny Control Panel**, switch on **Show in sidebar**, Start.
3. Open **Tiiny** in the sidebar, enter your device's address under Network, then log in under Account.

See `tiiny_panel/DOCS.md` for options and how access works.
